## 🌤️ About The Project

This is a premium, fully responsive weather dashboard built with vanilla web technologies. It fetches live weather data dynamically and updates the application's theme and backgrounds based on the current weather conditions. 

### 🌟 Features

- **Real-Time Data**: Get current temperature, humidity, wind speed, pressure, and "feels like" metrics instantly.
- **Dynamic Themes**: The application visually responds to the weather (e.g., changes to a dark cloudy theme when overcast, or a clear vibrant theme when sunny).
- **Glassmorphism UI**: A sleek, modern user interface featuring frosted glass effects and smooth micro-animations.
- **Local Time Conversion**: Automatically formats UNIX timestamp data for sunrise and sunset into your readable local time.
- **Dockerized**: Fully containerized using NGINX for fast, portable deployment.

### 🛠️ Built With

* HTML5
* CSS3 (Flexbox/Grid, CSS Variables, Animations)
* Vanilla JavaScript
* Docker & NGINX
* [OpenWeatherMap API](https://openweathermap.org/api)
